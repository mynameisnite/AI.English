# AI.English
AI.English — ваш бесплатный ИИ-партнёр для английского (Web и ПК). Три режима: свободная беседа, сценарные диалоги и «Найди ошибки», где бот специально делает неточности. Авторизация через Google, Apple или Email. Система прогресса, оценок и встроенный справочник. Монетизация: реклама, подписки и внутриигровые покупки.
